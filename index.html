About This Project

This web application is built using HTML and CSS, packaged inside a Docker container, and deployed seamlessly. Containerization ensures that the app runs exactly the same way regardless of the environment.

Core Features

  • Lightweight: Fast deployment using Docker.
  • Isolated: Runs in its own self-contained environment.
  • Scalable: Easy to replicate and host in the cloud.
